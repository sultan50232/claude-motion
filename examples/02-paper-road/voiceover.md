# Voice-over script: The Road of Paper (درب الورق)

One take per line, saved as `public/paper-road/vo/NN.wav`. The current timeline is fitted to the Google voice made by `npm run paper:vo`. If you record your own voice, drop the takes in and run `python3 scripts/retime.py src/history/stories/paper-road.json public/paper-road/vo` so the video fits the new takes, then `npm run paper:build`.

Delivery: warm documentary storyteller, Modern Standard Arabic, measured pace, a small pause on every «…». Where a line has a spoken form (numbers written out), read that.
